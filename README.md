# Prompt Compressor

## Features
- Efficient compression of prompts to save tokens.
- Easy to integrate with existing applications.
- Supports various input formats.

## Installation
To install the Prompt Compressor, run:
```bash
pip install prompt-compressor
```

## Quick Start Examples
```python
from prompt_compressor import compress

# Compress a prompt
compressed_prompt = compress("Give me a summary of the latest news.")
print(compressed_prompt)
```

## Token Savings Information
Using Prompt Compressor can significantly reduce the number of tokens used in prompts, minimizing costs when using services like OpenAI.

## Use Cases
- Ideal for applications that send numerous prompts to an AI service.
- Useful in scenarios where prompt length can be a limiting factor.
